# dotfiles: Hyprland + Noctalia

My Wayland desktop setup on Arch Linux ([CachyOS](https://cachyos.org)):

- **[Hyprland](https://hypr.land)** 0.56: compositor, configured in **Lua** (not `hyprland.conf`)
- **[Noctalia Shell](https://github.com/noctalia-dev/noctalia-shell)** 5.3: bar, launcher, lock screen, notifications, wallpaper, session menu, with colors taken from the wallpaper
- **Alacritty** as terminal (theme generated by Noctalia), **Ghostty** for the update plugin
- **Sunshine** scripts for remote streaming (Moonlight) on a virtual headless monitor

## Layout

```
config/
  hypr/          -> ~/.config/hypr
  noctalia/      -> ~/.config/noctalia   (settings, colors, plugins)
  alacritty/     -> ~/.config/alacritty
  ghostty/       -> ~/.config/ghostty
bin/             -> ~/.local/bin          (Sunshine scripts)
examples/sunshine/                        (example Sunshine and hypridle config)
packages.txt                              (base packages)
packages-sunshine.txt                     (streaming packages)
install.sh
```

The Hyprland config is split into modules loaded by `hyprland.lua`:

| File | Contents |
|---|---|
| `monitors.lua` | Monitors and workspace assignment: 1-8 on `DP-1`, 9-10 on `HDMI-A-1` |
| `autostart.lua` | Starts Noctalia, polkit agent, Sunshine, KWallet unlock |
| `environment.lua` | Cursor (`Oxygen_Zion`) and Qt variables |
| `lookandfeel.lua` | Gaps, borders, blur, animations, smart gaps |
| `input.lua` | `it` keyboard layout, 3-finger workspace gesture |
| `keybinds.lua` | Keybindings (see below) |
| `rules.lua` | Window rules and default `master` layout for every workspace |

## Installation

Requires Arch Linux (or a derivative) with [`paru`](https://github.com/Morganamilo/paru).
On plain Arch, `noctalia-qs`, `grimblast-git` and `google-chrome` come from the AUR. On CachyOS they are in the repos.

```bash
git clone https://github.com/yuky2020/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

The script:

1. installs the packages in `packages.txt` and `packages-sunshine.txt` with `paru -S --needed`;
2. moves existing configs to `~/.config/dotfiles-backup-<date>/`;
3. symlinks `~/.config/*` and `~/.local/bin/*` to the repo;
4. rewrites the wallpaper path in `config/noctalia/settings.json` to match your home.

Options:

- `--no-packages`: skip package installation
- `--no-sunshine`: skip the Sunshine scripts and remove their line from autostart

After installing:

1. Edit `config/hypr/monitors.lua` for your monitors. Run `hyprctl monitors` to see their names.
2. Put wallpapers in `~/Pictures/Wallpapers`. Noctalia and terminal colors are generated from the wallpaper.
3. Log out and pick Hyprland in your display manager.

Because the files are symlinks, every change made by Noctalia or by hand lands in the repo. A `git commit` saves it.

## Main keybindings

`SUPER` is the main modifier.

| Keys | Action |
|---|---|
| `SUPER + Return` | Terminal (alacritty) |
| `SUPER + D` | Noctalia launcher |
| `SUPER + W` | Browser |
| `SUPER + F` | File manager (thunar) |
| `SUPER + SHIFT + Q` | Close window |
| `SUPER + V` | Toggle floating |
| `SUPER + SHIFT + F` / `SHIFT + D` | Maximize |
| `SUPER + SHIFT + J` | Cycle active workspace layout: master, scrolling, dwindle |
| `SUPER + J` | Toggle split direction (dwindle) |
| `SUPER + L` | Lock screen |
| `SUPER + ESC` / `SHIFT + L` | Session menu |
| `SUPER + SHIFT + W` | Wallpaper selector |
| `SUPER + SHIFT + I` | Noctalia settings |
| `SUPER + S` / `SHIFT + S` | Scratchpad: show / move window |
| `SUPER + 1..0` / `SHIFT + 1..0` | Go to workspace / move window |
| `SUPER + M` | Exit Hyprland |
| `Print` / `ALT + Print` / `CTRL + Print` | Screenshot area / window / monitor |

## Noctalia plugins

They are included in the repo and enabled in `config/noctalia/plugins.json`. They come from [noctalia-plugins](https://github.com/noctalia-dev/noctalia-plugins):

- `arch-updater`: pacman, AUR and flatpak updates
- `file-search`: file search from the launcher
- `kde-connect`
- `monitor-layout`
- `screen-recorder`, `screen-shot-and-record`
- `hassio`: Home Assistant (disabled)

`plugins/hassio/settings.json` is excluded in `.gitignore` because it holds the Home Assistant URL and token. To use the plugin, enable it and enter URL and token in the Noctalia settings.

## Sunshine (remote streaming)

The scripts in `bin/` create a 1920x1080 virtual `HEADLESS` monitor and move the workspaces onto it when a Moonlight client connects. The physical screen turns off during the session and comes back as before on disconnect.

| Script | When it runs |
|---|---|
| `sunshine-start.sh` | At login (from `autostart.lua`): creates the headless monitor and starts Sunshine |
| `sunshine-connect.sh` | On client connect (`global_prep_cmd` "do") |
| `sunshine-disconnect.sh` | On client disconnect (`global_prep_cmd` "undo") |
| `sunshine-after-sleep.sh` | After suspend (hypridle `after_sleep_cmd`) |

Setup:

1. Copy `examples/sunshine/sunshine.conf.example` to `~/.config/sunshine/sunshine.conf`.
2. If you use hypridle, add the line from `examples/sunshine/hypridle-snippet.conf`.
3. The scripts assume the main monitor is `DP-1`. If yours has another name, replace it in the scripts.

The scripts work with both the Lua and the classic Hyprland config.

## Notes

- Cursor: `Oxygen_Zion`, from the `oxygen-cursors` package.
- Terminal font: JetBrains Mono.
- `autostart.lua` unlocks KWallet at login via `pam_kwallet_init`. If you don't use KWallet, remove the last two lines.
